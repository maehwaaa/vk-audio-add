## Дисклеймер

Скрипт использует неофициальные возможности ВК и вашу личную сессию. Используйте на свой риск, соблюдайте правила сервиса и не злоупотребляйте частотой запросов.

# VK Playlist → Мои аудиозаписи

Скрипт для браузера, который переносит **все треки из плейлиста ВК** в раздел «Мои аудиозаписи». Запускается в консоли разработчика на странице плейлиста. Прелесть данного скрипта заключается в том, что вы можете продолжать пользоваться браузером, переодически отвлекаясь на капчу (раз в 50 треков где-то).

## Зачем это нужно

ВК не позволяет одной кнопкой добавить весь плейлист в «Мои аудиозаписи», если вы просматриваете чужой или свой плейлист. Скрипт автоматизирует это: загружает полный список через API и добавляет треки по одному с паузами.

## Требования

- Браузер с консолью (Chrome, Edge, Firefox и т.д.)
- Авторизация на [vk.com](https://vk.com)
- Открытая страница плейлиста, например:

  `https://vk.com/music/playlist/195865032_84402291_829ccc35ad28b09d51`

## Быстрый старт

1. Откройте нужный плейлист по ссылке вида `vk.com/music/playlist/...`
2. Нажмите **F12** → вкладка **Console**
3. Скопируйте содержимое файла `vk-scrypt.js` и вставьте в консоль
4. Нажмите **Enter**
5. На вопрос «Продолжить с конкретной песни?» ответьте **0** (для первого запуска)
6. Не закрывайте вкладку, пока скрипт работает
   
## Настройки

В начале файла `vk-scrypt.js`:
| `SLEEP_BEFORE_NEXT_POST_REQUEST` | `4500` | Пауза между добавлением треков (мс). При капче увеличьте до `7000`–`10000` |

## Как это работает

### 1. Подготовка

Из URL страницы извлекаются:

- `owner_id` — владелец плейлиста
- `playlist_id` — ID плейлиста
- `access_key` — ключ доступа (если есть в URL)

Из `localStorage` берётся web-токен (`app_id:web_token:login:auth`) для запросов к API ВК.

### 2. Загрузка списка треков

1. **`audio.get`** — загрузка всего плейлиста порциями по 200 треков
2. **`audio.getById`** — добор `track_code` для треков, у которых его не было

Список переворачивается: добавление идёт **с низа плейлиста к верху**, чтобы порядок в «Мои аудиозаписи» совпал с плейлистом.

### 3. Добавление каждого трека

Для каждой песни пробуются три способа (по очереди, пока один не сработает):

1. **`vk.api('audio.add')`** — внутренний вызов, как при нажатии «+» на сайте
2. **`api.vk.com/method/audio.add`** — официальный API с `access_token`, `track_code`, `access_key`
3. **`al_audio.php?act=add`** — запасной внутренний эндпoинт ВК

Между треками — пауза ~4.5–6 секунд (настраивается + случайная добавка).

### Схема взаимодействия

```
Браузер (ваша сессия vk.com)
    │
    ├─► api.vk.com/method/audio.get      — список плейлиста
    ├─► api.vk.com/method/audio.getById  — метаданные (track_code)
    ├─► vk.api / api.vk.com/audio.add    — добавить в «Мои аудиозаписи»
    └─► vk.com/al_audio.php              — запасной способ добавления
```

## Продолжение после остановки

Если скрипт прервали (капча, F5, `stopVkAdd = true`):

1. Обновите страницу при необходимости (F5)
2. Снова откройте плейлист и запустите скрипт
3. На первый вопрос ответьте **1**
4. Введите **часть названия** следующей необработанной песни — её покажет строка «Следующая к добавлению» в консоли

Достаточно уникального фрагмента названия или исполнителя, регистр не важен.

## Управление

| Действие | Команда |

| Остановить скрипт | В консоли: `stopVkAdd = true` |
| Мгновенно прервать | Обновить страницу (**F5**) |
| Замедлить добавление | Увеличить `SLEEP_BEFORE_NEXT_POST_REQUEST` |

## Капча и ограничения ВК

- При массовом добавлении ВК может запросить **капчу** (ошибка с кодом 14)
- Скрипт предложит вручную добавить одну песню через «+», пройти проверку и нажать OK — затем попробует продолжить. Можно открыть еще одну вкладку только для добавления трека, чтобы пройти капчу и вернуться обратно на страницу со скриптом
- Для больших плейлистов (200+ треков) иногда лучше добавлять **порциями** с перерывами между сессиями
- Это ограничения платформы, увы

## Частые проблемы

**«На странице нет элементов» / не находит плейлист**  
Убедитесь, что вы на странице `vk.com/music/playlist/...`, а не в поп-апе поверх другой страницы со старой вёрсткой.

**«ДОБАВЛЕНИЕ НАЧАТО (0 шт.)»**  
На первый вопрос нужно ответить **0**, а не **1**.

**«Ошибка доступа»**  
Обычно означает, что один из запасных методов (`al_audio.php`) не подошёл без `hash`.

**`track_code: "НЕТ"` в консоли**  
Тут только сообщить — возможно, ВК снова изменил API.
